Hermes Agent alternative: MausBot

Hermes Agent is a built-in MausBot engine: run Hermes with a GUI, rooms, automations and phone apps beside Claude and Codex bots, or use MausBot instead.

Hermes Agent is Nous Research's self-improving open-source agent, reached through chat gateways and run on a server or your PC. MausBot is a chat app of bots, and Hermes is one of its engines: run Hermes with a GUI, next to Claude and Codex bots, with automations, rooms and phone companions, or run MausBot instead of a Hermes gateway.

What Hermes Agent is

Hermes Agent launched on February 25, 2026 and has about 249,000 GitHub stars. It writes its own skills, remembers across sessions, runs cron jobs and subagents, and answers on Telegram, Discord, Slack, WhatsApp, Signal, email and more. It runs on Linux, macOS, native Windows and a $5 VPS, with a desktop app since June 2026 and official hosting through Nous Portal's Hermes Cloud.

Launched: February 25, 2026 . Sources: Hermes Agent on GitHub ; Hermes Agent docs: Windows (native) .

Why people look for a Hermes Agent alternative

It is one agent; profiles give you several isolated ones, not a team in one room.

What MausBot is

MausBot is a free, open-source chat app where every contact is an AI bot with its own model, its own computer, and its own connected apps. Bots run on the claude , codex , and grok CLIs installed on your own machine, with your existing logins, so one bot can be on Claude and the next on ChatGPT. Shell commands and file edits surface as Allow / Deny cards before they run, bots share group rooms and hand work to each other, and your data stays in ~/.openmausbot on your disk. It is published on GitHub under Apache 2.0, with iOS and Android companions, and paid Cloud plans from $15 a month keep bots working with the laptop closed.

Frequently asked questions

Can I run Hermes inside MausBot? Yes. MausBot spawns hermes acp with the provider you configured in ~/.hermes/config.yaml, and the bot gets MausBot's chat, rooms, automations, connected apps and phone companions. When Hermes asks before a command, the request appears as a MausBot approval card. Does MausBot gate every Hermes command? No. MausBot shows Hermes's own permission requests as cards; if Hermes is set not to ask, its shell runs without a card. Keep Hermes's approval mode on. Is there a Hermes Agent desktop app? Yes, Hermes Desktop, in public preview since June 2, 2026 for macOS, Windows and Linux. MausBot is a different kind of app: a team of bots, of which a Hermes bot can be one. Which is safer? Both have real controls. Hermes has approval modes and pairing codes but also a --yolo flag and a 2026 CVE list; MausBot's approval cards and loopback-only harness are the default for Claude, Codex and Grok bots; a Hermes bot keeps Hermes's own mode.
